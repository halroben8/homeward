# Homeward

A cute little exploration game about a lost cat finding his way home.

You play an orange tabby who has wandered too far from home. Every run, your
collar tag shows a new home address somewhere in a friendly city neighbourhood —
remember it, read the street signs, and make your way back. Along the way,
well-meaning people will pet you, offer treats… and sometimes try to take you
home with them. If someone scoops you up, you'll have to work the latch,
distract your host, and slip out the door — then outrun a very determined
60-second pursuit.

**Status:** in active development. Android builds are shared as APKs, and a
browser-playable web version is planned for this repo so anyone can try it
from a link — no install needed.

Built with Godot 4.
